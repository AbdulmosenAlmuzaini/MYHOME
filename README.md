# 🌱 كيمياء وطن أخضر
### كيمياء اليوم… استدامة الغد 🌱

مبادرة تعليمية تفاعلية باللغة العربية موجهة لطالبات المرحلة الثانوية، تربط بين الكيمياء والاستدامة والجهود الوطنية للمملكة في المحافظة على البيئة والموارد الطبيعية.

المشروع مبني ليعمل **100% وبشكل أصيل ومباشر على منصة Vercel** باستخدام:
* **Vercel Postgres** (قاعدة البيانات الأساسية)
* **Vercel Blob** (مساحة تخزين الملفات والصور)
* **Secure JWT Sessions** (نظام مصادقة وإدارة المشرفات الداخلي)

## 🚀 دليل الإعداد والنشر على Vercel بضغطة زر (بدون أي خدمات خارجية)

### 1. استيراد المشروع في Vercel
1. ادخلي إلى [Vercel Dashboard](https://vercel.com/new).
2. اختاري مستودع المشروع `AbdulmosenAlmuzaini/MYHOME` واضغطي **Import**.

### 2. تفعيل قاعدة بيانات Vercel Postgres
1. بعد فتح المشروع في Vercel، اذهبي إلى تبويب **Storage**.
2. اضغطي على **Create Database** واختاري **Postgres**.
3. اضغطي **Continue** ثم **Connect to Project**.
*(سيتم تلقائياً ربط قاعدة البيانات وإنشاء الجداول ذاتياً من خلال الكود دون الحاجة لكتابة أي SQL يدوي).*

### 3. تفعيل مساحة تخزين Vercel Blob (لرفع الملفات)
1. في نفس تبويب **Storage**، اضغطي على **Create Database / Store**.
2. اختاري **Blob** واضغطي **Continue** ثم **Connect to Project**.

### 4. كلمة مرور لوحة المشرفات (اختياري)
في صفحة **Settings -> Environment Variables** في Vercel:
* أضيفي `ADMIN_PASSWORD` = كلمة المرور التي ترغبين بها (الافتراضية: `kimia2026`).

### 5. النشر (Deploy)
اضغطي **Deploy**. وستعمل قاعدة البيانات ورفع الملفات ولوحة الإدارة بالكامل من داخل Vercel مباشرة!
